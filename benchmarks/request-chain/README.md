# 请求链路基准候选 v0.1

本批为 #35 的内部材料准备，不是整票验收。全部由 AI 起草，等待人工逐条核验。`origin=ai_draft`、`review_status=pending_human_review`、`human_review=null` 同时写在机器记录中；答案标签也各自标记待核验。程序通过结构、引用和规则契约不改变此状态，不能由 #40 当作人工基准导入。这里没有人工签名、真实模型分数或可发放固定题库。

范围：系统、前端、网络三领域 × 基础/进阶/综合 × 两案例家族，18个基础候选及36个答案标签候选；另附每例一个实际条件变化候选和只换标题的反例。绑定现有目录 fullstack-v1.0.0 六个叶子、三个背景；每题只对明确受考主能力记候选证据，不把提到的组件都算通过。综合档采用同一主能力下多个约束的联合判断，实际难度与语义是否充分仍由人工审阅。

## 来源与复现

`sources.json` 是官方来源的简短摘录。实际读取时间为2026-09-09；Python采用CPython官方仓库v3.14.5固定标签（而非会更新的/3.14文档）；RFC使用编号固定版本；DOM与WCAG Understanding为读取时快照，完整响应SHA-256写入version，定位写入locator。摘录按空白折叠后取精确文本，省略处用[…]分隔；不是完整文档副本。HTTP locator另含明确标记的AI中文规范摘要（待人工核验），用于保留重试策略及两类例外；该摘要不是逐字引用，不能与text内的exact excerpts混同。SHA只绑定抓取版本，不证明推理正确；公开网页未来变化后应形成新材料版本，不静默改旧依据。

文档只支持标准/语言规则；每题资源数值、时序、日志、回执均显式属于教学假设，不能称作官方来源观测到的运行事实。已列出的脚本/协议名称不是可执行作业，本批不运行用户代码。

人工逐条核验时需检查：来源原位置及适用版本、教学假设能否支持推理、正确与错误标签是否成立、补证结论是否被误判、白话/多解是否被不当排除、变式是否真正改变所需判断、帮助文本是否给出本题方向。若不能确定就留下缺项或争议，不强签通过。当前没有人工核验接口；本批不扩展人工逐题判卷产品权限。
